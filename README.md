# ABAP JSON Architect

**[🇺🇸 English]**

**ABAP JSON Architect** is a powerful, browser-based IDE that automates the conversion of JSON payloads into production-ready SAP ABAP code. Built entirely in a single HTML file — no installation, no backend, no data leaving your browser.

### ✨ Key Features

- **Instant ABAP Generation:** Transforms complex JSON into ABAP `TYPES:` definitions (Structures & Table Types). Table types (`TT_`) are only generated when the JSON field is an actual array `[ ]` — no unnecessary bloat.
- **Monaco Editor:** The same engine powering VS Code. Real-time JSON syntax highlighting, bracket matching, and inline error markers as you type.
- **JSON Formatter:** Cleans up minified or messy JSON with one click.
- **JSON Tree View:** Visual breakdown of your JSON structure with type badges (string, number, boolean, array, object). Click any node to instantly jump to that line in the editor.
- **Validation Panel:** Dedicated error tab listing every JSON issue with exact line and column numbers. Click an error to navigate directly to it.
- **Mapping Support:** Automatically generates `/ui2/cl_json` name mapping logic for field name transformations.
- **Code Templates:** Ready-to-use HTTP Client & Bearer Token boilerplates for Web Service consumption.
- **Download & Copy:** Export generated ABAP Types, Mapping logic, or Code Templates as `.abap` files with one click.
- **3-Panel Layout:** JSON Tree / Editor / Output panels side by side, fully resizable by drag.
- **Smart Naming:** Configurable prefixes (e.g. `TS_`, `TT_`) and suffix support to match your corporate naming standards.
- **TR / EN Language Support:** Full UI available in Turkish and English — toggle with one click.
- **Dark / Light Theme:** Persistent theme preference.
- **Keyboard Shortcuts:** Power-user shortcuts for convert, format, validate, copy, and more.
- **Zero Setup:** Pure HTML/CSS/JS, zero dependencies. Runs directly in any modern browser.

**[🇹🇷 Türkçe]**

**ABAP JSON Architect**, JSON verilerini anında canlı kullanıma hazır SAP ABAP kodlarına dönüştüren, tarayıcı tabanlı bir IDE'dir. Tek bir HTML dosyasından oluşur — kurulum yok, sunucu yok, verileriniz tarayıcınızdan çıkmaz.

### ✨ Öne Çıkan Özellikler

- **Hızlı ABAP Üretimi:** Karmaşık JSON yapılarını anında `TYPES:` tanımlarına (Structure & Table Type) dönüştürür. Tablo tipleri (`TT_`) yalnızca gerçek JSON dizileri `[ ]` için üretilir — gereksiz tip şişmesi yoktur.
- **Monaco Editör:** VS Code'u çalıştıran motor. Gerçek zamanlı JSON sözdizimi renklendirme, parantez eşleştirme ve yazarken hata işaretleme.
- **JSON Formatlama:** Sıkıştırılmış veya dağınık JSON'u tek tıkla temizler ve okunabilir hale getirir.
- **JSON Ağaç Görünümü:** JSON yapısını tip rozetleriyle (string, number, boolean, array, object) görsel olarak sunar. Herhangi bir alana tıkla, editör o satıra otomatik atlar.
- **Doğrulama Paneli:** Her JSON hatasını satır ve sütun bilgisiyle listeleyen ayrı sekme. Hataya tıkla, direkt oraya git.
- **Mapping Desteği:** Alan adı dönüşümleri için `/ui2/cl_json` mapping mantığını otomatik oluşturur.
- **Kod Şablonları:** Web servis tüketimi için hazır HTTP Client ve Bearer Token kod blokları sunar.
- **İndir & Kopyala:** Üretilen ABAP Types, Mapping veya Code Template çıktılarını tek tıkla `.abap` dosyası olarak indir ya da panoya kopyala.
- **3 Panelli Arayüz:** JSON Ağacı / Editör / Çıktı panelleri yan yana, sürükleyerek serbestçe yeniden boyutlandırılabilir.
- **Akıllı İsimlendirme:** Kurumsal standartlarınıza uygun önek (örn. `TS_`, `TT_`) ve sonek desteği.
- **TR / EN Dil Desteği:** Arayüzün tamamı Türkçe ve İngilizce olarak mevcuttur — tek tıkla geçiş.
- **Koyu / Açık Tema:** Tema tercihi tarayıcıda kalıcı olarak saklanır.
- **Klavye Kısayolları:** Dönüştür, formatla, doğrula, kopyala ve daha fazlası için kısayol desteği.
- **Kurulumsuz:** Saf HTML/CSS/JS, sıfır bağımlılık. Herhangi bir modern tarayıcıda doğrudan çalışır.

## 🚀 Usage / Kullanım

1. Download the `ABAP_JSON_Architect.html` file. / `ABAP_JSON_Architect.html` dosyasını indirin.
2. Open it in any modern web browser. / Herhangi bir modern tarayıcıda açın.
3. Paste or type your JSON in the center editor. / JSON'unuzu merkez editöre yapıştırın veya yazın.
4. ABAP code is generated instantly in the right panel. / ABAP kodu sağ panelde anında üretilir.
5. Download or copy the output with one click. / Çıktıyı tek tıkla indirin veya kopyalayın.
